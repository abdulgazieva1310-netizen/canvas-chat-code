# Issue #82 QA evidence — 2026-10-29

## Acceptance coverage

| Requirement | Implementation and evidence |
| --- | --- |
| Define initial choices | Classic, Sage and Rose are documented color variants of the existing procedural interviewer. Profile cards, local portraits and 3D clothing share one catalog. |
| Save the selection | Profile UI tests cover all three choices, explicit save and shared profile-cache updates. Selecting without saving leaves the persisted preference unchanged. API tests cover all IDs, invalid values, omission preservation, reset, logout/login and restart persistence. |
| Apply to subsequent interviews | Interview pages read the saved profile preference. Existing tests cover the saved Sage choice reaching 3D; failure scenarios load each of the three saved choices in a fresh room. Reopening a historical session uses the current profile choice, as documented. |
| Fallback when unavailable | The selected local portrait appears with 3D hidden or failed. All three failure scenarios preserve the answer draft, cached profile and cached interview. Unknown client IDs resolve to Classic. Existing tests also cover reduced motion and text/voice controls. |
