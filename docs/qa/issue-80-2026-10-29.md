## Enablement

Follow `docs/security/coding-runner.md` to deploy the private gateway and executor,
then set `CODING_RUNNER_URL` and a matching secret `CODING_RUNNER_TOKEN` in the API
environment and restart. Use an English Junior Technical interview for Backend,
Full Stack, Python, Java or C++ to receive a reviewed first question. Subsequent
unreviewed AI questions deliberately remain static-review-only. No hosted
deployment or production environment settings were changed by this work.
